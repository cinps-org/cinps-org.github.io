ExamSphere workflow

  1. Authorised instructors create questions within their assigned course scope.
  2. Instructors create, assemble and publish examinations independently within their assigned courses; no Admin pre-approval step is required.
  3. Students take published examinations and submit once.
  4. Instructors review submissions, enter marks and publish results.

The browser timer is a convenience, not a tamper-proof server clock. This version uses instructor-authorised grading; no answer key is sent to student devices.
